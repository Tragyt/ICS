# ICS

This project provides a simulated Industrial Control System (ICS) network environment, implemented through Docker containers orchestrated with Docker Compose.

The repository includes multiple configurations of the network:

- **Fully Virtualized – Insecure Environment**
  Branch: `unsafe-env`
  Documentation: [docs/unsafe.md](docs/unsafe.md)

- **Fully Virtualized – Secure Environment**
  Branch: `virtual-safe-env`
  Documentation: [docs/virtual-safe.md](docs/virtual-safe.md)

- **Physical Environment**
  Branch: `main`
  Documentation: [docs/physical-safe.md](docs/physical-safe.md)
